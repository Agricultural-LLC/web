# functions

## Overview

Directory `functions`. Cloud Functions for Firebase.

## Build & Test

- Install dependencies with `npm --prefix functions ci` from the repo root.
- Lint with `npm --prefix functions run lint`.
- Run local emulators with `npm --prefix functions run serve` when Function behavior changes.

## Notes

- Keep Firebase project identifiers stable unless an explicit infrastructure migration is requested.
- Do not commit service account keys or local emulator debug output.
